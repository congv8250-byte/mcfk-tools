# MCFK Tools

Mod Fabric cho Minecraft 26.1.2 và 26.2: cúp 3x3, xẻng 3x3, rìu chặt cây, xô nước vô hạn, Veinminer tùy chỉnh.

Code nằm trong `mod/src`. GitHub Actions tự lấy template Fabric chính thức, ghép code vào và build ra file jar.
Jar có trong tab Actions (Artifacts) và trong mục Releases ("latest-build").
