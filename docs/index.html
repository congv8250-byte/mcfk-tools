MCFK Tools

Cúp 3x3, xẻng 3x3, rìu chặt cả cây, xô nước vô hạn và Veinminer tùy chỉnh.

Tải cho 26.1.2mcfktools-26.1.2.jar Tải cho 26.2mcfktools-26.2.jar

Chọn đúng phiên bản Minecraft của bạn. Cần Fabric Loader 0.19.3 trở lên, Fabric API và Java 25.

Cài đặt

  1. Cài Fabric Loader đúng phiên bản Minecraft.
  2. Bỏ Fabric API và file mcfktools vào thư mục mods (máy chơi hoặc máy chủ).
  3. Vào game, gõ /tools.

Nếu cài trên máy chủ thì người chơi không cần cài mod vẫn dùng được.

Tính năng và lệnh

  • Cúp 3x3 và xẻng 3x3 (giữ Shift để đào 1 block)
  • Rìu chặt cả cây
  • Xô nước vô hạn
  • Veinminer: /veinminer gui, /veinminer range, /veinminer max, /veinminer mode
  • Lấy đồ: /tools hoặc /congcu
